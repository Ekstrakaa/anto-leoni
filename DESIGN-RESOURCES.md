# Motion resource

Text entrance direction researched from Arc Text Reveal, listed on 21st.dev:
https://docs.21st.dev/@kuratlielia/components/text-reveal
https://github.com/kuratlielia/arc-library/blob/main/public/r/text-reveal.json

This site uses an original CSS implementation of the word/line entrance pattern, fitted to the existing React layout. No new runtime dependency. Includes reduced-motion handling, keyboard focus, and pointer-gated hover feedback.

Supplied photos are real user assets. Larger gallery files are resized for web delivery, without creative alteration. Food photos retain the original dishes; no ingredients, quantities or nutrition values are inferred.
